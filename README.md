# NetBridge

**NetBridge** — Yerli API Gateway & Microservice Yönetim Aracı  
Ocelot benzeri, .NET Core tabanlı bir API yönlendirme ve yönetim kütüphanesi.

---

## 🚀 Özellikler
- Routing (Upstream → Downstream)
- JWT/OAuth2 Authentication
- Rate Limiting
- Response Caching (Memory)
- Service Discovery (host/port bazlı)
- QoS (Retry + Circuit Breaker)
- Logging

---

## 📦 Kurulum
NuGet üzerinden yükleyin:
```bash
dotnet add package NetBridge
